## Why

The Firebase CLI's "User Token" auth method (`--token` / `FIREBASE_TOKEN`, generated by `firebase login:ci`) is deprecated and will be removed in a future major version of `firebase-tools`. The GitHub Actions deploy job relies on it, so it will break on a future CLI upgrade and currently ships a long-lived credential that Google's guidance says to avoid.

## What Changes

- Replace `--token "${{ secrets.FIREBASE_TOKEN }}"` in the deploy job with Application Default Credentials via a Google Cloud service account key (`GOOGLE_APPLICATION_CREDENTIALS`).
- Add a new GitHub Actions secret (`GCP_SA_KEY`) holding the service account JSON key.
- Remove the now-unused `FIREBASE_TOKEN` secret from the repo.
- No application (TypeScript/Angular) code changes.

## Capabilities

### New Capabilities

None — this is CI/tooling only; no product capability or spec-level behavior changes.

### Modified Capabilities

None.

## Impact

- `.github/workflows/ci.yml` (deploy job)
- GitHub repository secrets (`GCP_SA_KEY` added, `FIREBASE_TOKEN` removed)
- Google Cloud IAM (a service account with the roles required to deploy Hosting and security rules)
